## Critical Success Factors

### 1. Respond Fast
- Emails: <2 hours (sets expectation you're attentive)
- Reddit: <4 hours same day (shows you care)
- Twitter: <24 hours (conversation stays active)

**Why**: People get a feeling for who you are from your responses. Fast = serious founder.

### 2. Track Everything
- Update tracking sheet DAILY
- Review Friday weekly summary
- Use data to decide where to focus Week N+1

**Why**: What gets measured gets managed. You'll see patterns others miss.

### 3. Stay Authentic
- Don't be salesy
- Actually engage with feedback (even negative)
- Share wins AND failures
- Be a person, not a brand

**Why**: Early users invest in founders, not companies. Show up as yourself.

### 4. Fix Bugs Immediately
- User reports bug → Fix same day if possible
- Can't fix same day → Email user explaining
- No radio silence (death for early stage)

**Why**: Bugs destroy trust. Fast response rebuilds it.

### 5. Ask for Feedback, Act On It
- "What's not working?" 
- "What would make this better?"
- If multiple users say same thing → build it
- Tell users "Based on feedback, we're building X"

**Why**: Users become advocates when they see you listen.

## What Happens If You Hit Roadblocks

### "No one's signing up from this channel"
- Stop after 3 attempts
- Switch to different channel
- Save time for what works

### "Users are signing up but not using features"
- Email them: "What would make this useful?"
- Do 1-1 calls with interested users (30 min each)
- Iterate based on feedback

### "I found a bug / something's broken"
- Email developer immediately
- Tell users the status ("We found it, working on fix")
- Don't hide problems

### "I'm exhausted"
- That's normal Week 2-3
- Rest > burnout
- Focus on 1 channel instead of 5
- Simplify
